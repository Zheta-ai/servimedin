# Servimedin

Página web para un consultorio de tratamiento del dolor y dos farmacias en Tulcán, Ecuador. El paciente agenda su cita o cotiza su receta y el mensaje llega listo al WhatsApp del consultorio.

- HTML, CSS y JavaScript sin frameworks.
- Formulario de cita con validación y "Cotiza tu receta" con foto.
- Probada en navegador real a 1440, 1024, 768 y 390 px.

Hecha por [Sebastián Montalvo](https://github.com/Zheta-ai).
